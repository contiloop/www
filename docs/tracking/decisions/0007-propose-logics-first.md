# 0007 Drafting an unsettled section proposes several logics first

Context: an author asking for a quick draft of a section whose claim-by-claim logic is not agreed would otherwise get text built on the AI's own chain, which is the failure the plugin addresses.

Decision: the skill proposes two or three candidate logics for the section from what is agreed, states what each makes the section argue, recommends one, and drafts only after the author picks or fixes one. The same several-alternatives rule applies to proposals of message framing, structure and renderings of a flagged sentence.

Alternatives: drafting at once and marking assumptions (the author reads prose and reacts to it instead of deciding the chain); refusing until the logic is agreed (no help toward agreeing it); a single proposed logic (accepted by inertia).

Consequences: a draft request for an unsettled section ends in a proposal, not text; rejected candidate logics are recorded so they are not proposed again.
