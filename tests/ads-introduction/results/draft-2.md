## Introduction

Translation technology has advanced. However, existing translation services have cost and security issues. Small, domain-specific translation models that can run locally must therefore be developed. Training such a model requires parallel data. Constructing parallel data manually, however, is difficult. Another source of supervision must therefore be found. Teacher LLMs can provide high-quality translation supervision. But applying them to the entire dataset is expensive. Yet even a small amount of high-quality parallel data can improve the student model's translation performance. Which sentences, then, should receive the teacher's annotation budget when that budget is limited? To answer this question, we propose QE-guided Active Data Selection (ADS). ADS evaluates the student model's translations with a QE model and selects the sentences with low QE scores first.
