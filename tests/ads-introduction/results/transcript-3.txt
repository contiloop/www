> ## Introduction

> Translation technology has advanced. However, using existing translation services raises cost and security issues. Therefore, a small, domain-specific translation model that can run locally must be developed. Training such a model requires parallel data, but constructing parallel data manually is difficult. An alternative source of supervision is therefore needed. Teacher LLMs can provide high-quality translation supervision, but applying them to the entire dataset is expensive. Even a small amount of high-quality parallel data, however, can improve the student's translation performance. Which sentences, then, should receive the teacher's annotation budget when that budget is limited? To answer this question, we propose QE-guided Active Data Selection (ADS). ADS evaluates the student's translations with a QE model and selects the sentences with low QE scores first.
