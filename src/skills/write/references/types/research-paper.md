# Rules for a research paper

Rules for every sentence of a paper read by reviewers and researchers who judge the claims against the evidence. Read with `references/writing-rules.md` whenever the record's type line names a research paper; rules 31 to 34 of that file govern when this file is read, that it wins on conflict, and how a rule enters it. Each rule is numbered and carries its test and its disposition (cut, rewrite, ask the author), in the form of the shipped rules file.
