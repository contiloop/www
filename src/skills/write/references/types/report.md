# Rules for a report

Rules for a report read by someone who will decide or act on it, at every level: how the structure and the section plans are shaped, how a section's logic is proposed, and how its sentences are written. Read whenever the record's type line names a report; rules 31 to 34 of `references/writing-rules.md` govern when this file is read, that it wins on conflict, and how a rule enters it. Each rule is numbered, names the level it applies at, and carries its test and its disposition (fold, cut, rewrite, ask the author).
