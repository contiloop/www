# Rules for a presentation script

Rules for every sentence of a script spoken to listeners who do not read along. Read with `references/writing-rules.md` whenever the record's type line names a presentation script; rules 31 to 34 of that file govern when this file is read, that it wins on conflict, and how a rule enters it. Each rule is numbered and carries its test and its disposition (cut, rewrite, ask the author), in the form of the shipped rules file.
