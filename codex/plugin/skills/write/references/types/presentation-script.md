# Rules for a presentation script

Rules for a script spoken to listeners who do not read along, at every level: how the structure and the section plans are shaped, how a section's logic is proposed, and how its sentences are written. Read whenever the record's type line names a presentation script; rules 31 to 34 of `references/writing-rules.md` govern when this file is read, that it wins on conflict, and how a rule enters it. Each rule is numbered, names the level it applies at, and carries its test and its disposition (fold, cut, rewrite, ask the author).

## Structure

1. Core and non-core are separated before the structure is proposed. Each core point is a step of its own in part 2 of the record; a non-core point is said in a few words inside the step that uses it and is never a step. Test: for each step in part 2 and each claim in part 3 that stands as its own sentence, is it a core point of the talk? No → fold it into the step or sentence that uses it. Applies when the structure and the section plans are proposed, when a section's logic is proposed, and when a draft is checked.
