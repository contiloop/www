# Rules for a report

Rules for every sentence of a report read by someone who will decide or act on it. Read with `references/writing-rules.md` whenever the record's type line names a report; rules 31 to 34 of that file govern when this file is read, that it wins on conflict, and how a rule enters it. Each rule is numbered and carries its test and its disposition (cut, rewrite, ask the author), in the form of the shipped rules file.
