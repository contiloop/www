# Rules for an essay

Rules for every sentence of an essay read by a general reader who judges the argument by its own line. Read with `references/writing-rules.md` whenever the record's type line names an essay; rules 31 to 34 of that file govern when this file is read, that it wins on conflict, and how a rule enters it. Each rule is numbered and carries its test and its disposition (cut, rewrite, ask the author), in the form of the shipped rules file.
